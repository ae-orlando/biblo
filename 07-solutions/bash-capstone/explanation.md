# Reference: integration without destructive automation

The reference parses bounded options, captures NUL-delimited find output, waits for its process-substitution producer and uses associative arrays for buckets. GNU stat supplies bytes. Sorting is count-descending with a byte-order tie-breaker; sed consumes the stream without an early-close SIGPIPE.

It is intentionally GNU/Linux-specific and not safe as a coherent snapshot of a concurrently changing tree. Bash arithmetic has finite signed range. A robust production inventory may need a different language, streaming design and consistency policy.

Verification: `python3 90-tools/practice.py check bash-capstone --reference`.
