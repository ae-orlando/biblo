# Responsive CSS — progressive hints

1. Begin with readable normal flow and a narrow single column; inspect actual boxes before adding layout complexity.
2. Flex can wrap controls; grid can express columns. Intrinsic minimums/long tokens may require deliberate min-width/track and wrapping choices.
3. Use content-based breakpoints, a centered bounded container, opaque readable colors and visible :focus-visible styling. Hiding overflow is not a repair for missing access to content.
